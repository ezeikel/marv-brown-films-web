## Cloudflare

`cloudflare/` holds a Cloudflare Worker that serves a captured copy of the site as it was deployed on Vercel in 2019
(this Next 8 source is not rebuilt for it). The DNS records, the cutover and rollback scripts, the parity evidence and
the handover notes are in `docs/cloudflare/`; `docs/cloudflare/CUTOVER.md` says where the move stands.
